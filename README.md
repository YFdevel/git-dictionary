# Git Dictionary — справочник команд Git (React + Vite + Electron)

«Цель → команда»: выбираете, что нужно сделать («изменить комментарий последнего коммита»),
заполняете параметры (сообщение, ветка, remote…) — приложение собирает готовую команду
и копирует её как чистый текст UTF-8, поэтому вставка в терминал не вызывает конфликтов форматов.

## Запуск (Node.js 18+)

    npm install
    npm run dev      разработка: Vite + Electron с hot-reload
    npm start        сборка фронтенда и запуск Electron из dist
    npm run dist     установщики (NSIS / AppImage / DMG) в release

## Почему вставка «без конфликтов форматов»

- копирование идёт через clipboard.writeText в главном процессе Electron — в буфер
  попадает только plain text (UTF-8), без HTML/RTF-разметки;
- спецсимволы (кавычки, обратная косая черта, $, обратный апостроф) экранируются
  по правилам выбранной оболочки (Bash / CMD / PowerShell);
- все файлы проекта — UTF-8; если в старом cmd.exe кириллица отображается неверно,
  выполните команду: chcp 65001

## Как добавить команду

Допишите объект в src/data/commands.js: поле command — шаблон с плейсхолдерами вида
{{name}} и, при необходимости, условными блоками {{#name}} … {{/name}}
(фрагмент попадает в команду, только если поле заполнено).
